# Homezee - MVP Plan (draft)

## MVP Features
- Choose city and area, then browse by category
- Listing cards with call/WhatsApp buttons, ratings, price range
- Daily-helper directory (bai, doodh, sabji, laundry) with rates, timings, area covered
- "Speciality of this city" section
- Owner-direct rental listings (no brokerage)
- Hindi / English language options

## Proposed Stack
Mobile-first PWA (React) with a Firebase or Supabase backend. Installable on phones, no app store needed at first, can become a native app later.

## Open Decisions
1. Platform: PWA (recommended) vs Android vs website
2. Launch city / area for the first data
3. Who adds listings: seeded by us only, or providers and users self-signup
4. Final app name: working name is **Homezee**
